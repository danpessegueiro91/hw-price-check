Como interpretar o arquivo

Uma lista identifica modelos da série; não certifica a autenticidade de uma peça individual. Para confirmar uma variante, compara fotografias, ano e detalhes do casting. Os valores só devem ser apresentados quando existe uma amostra adequada de vendas comparáveis.
